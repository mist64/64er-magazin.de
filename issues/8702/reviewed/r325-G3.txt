== FUTURETEUFELCHEN-CANDIDATE ==  (recorded, not added; owner default is none)
1. 79 Tips & Tricks für Profis, p79, "Turbo-POKE für den C 64/128". Print: "POKE 53269,1: POKE 53265,10" and
   "POKE 53269, PEEK (53269) AND 254: POKE 53265, 27". Right: 53296 ($D030, the C 128 clock register in C 64 mode),
   which the same issue prints itself on p72 ("POKE 53296,1 beziehungsweise POKE 53296,0 im C 64-Modus") -- the
   evidence is on the page (route 2/3), not recalled. Misleads: 53269 is $D015, the VIC sprite-enable register; a
   reader who types the tip switches sprite 0 on and blanks the screen (53265,10) but the CPU stays at 1 MHz.
   Impact REASONED, not run. Crop v12.
2. 136 Von Basic zu Assembler, p138, 16-bit table example. Print: "LDA #$05 / ASL / TXA ;und ins X-Register
   schieben". Right: TAX. Misleads: TXA copies X into A, destroying the doubled index, and LDA TAB,X then indexes
   with whatever X held; the comment says the opposite of what the opcode does. The p138 right-column example
   prints TAX for the same step. Impact REASONED, not run. Crop v02.
3. 136, p138, "2) RTS vermindert dann den Stapelzeiger um 2". Right: RTS INCREMENTS the stack pointer by 2 (pull
   = increment on the 6502). Misleads a beginner about stack direction in the very passage meant to explain it.
   Source: 6502 instruction semantics (MOS programming manual, recalled -- route 4, not cited from a document at
   hand). Crop v02.
4. 136, p136: "auf die Adresse $B248, wo die Ausgabe der Fehlermeldung »SYNTAX ERROR« ausgegeben ... wird".
   On the C 64, $B248 is the ILLEGAL-QUANTITY error entry (FCERR), so USR without a vector gives ?ILLEGAL QUANTITY
   ERROR; the article's own C 128 sentence says the same for $7D28. Disk witness: prg/flpt c64 line 530 restores
   785,72/786,178 = $B248, confirming the address, not the message. The message claim rests on RECALLED ROM
   knowledge, no ROM image on this machine -- lowest confidence; impact small (wrong error name). Crop v01.
